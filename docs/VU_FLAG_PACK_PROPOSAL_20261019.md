# مرشح تجميع أعلام FMAC

**النتيجة اللاحقة:** اكتملت النسخة المشروطة ثم المباشرة؛ أزيل مفتاحالتجربة من المصدر النهائي. اجتاز628اختبارًا ومليونيتركيبة،والتحسنالصافينحو0.98%فيالحملالمعزول. بقي التغيير فيالتطويردونترقيةالحزمة. [القبولوالحدود](VU_FLAG_PACK_RESULT_20261019.md). ما يلي وصف الاقتراح قبل الاختبار.

الاقتراح: العينة `vu-hot-profile-20261019` تعطيupdateFmacFlagsنحو2.8–3.2%منالعمليةوحدها،ونحو6%منالعيناتداخلVU.run. تُختبر طريقة جدول من16عنصرًا لتحويل أعلام المسارات الأربع إلى حقولMAC، بدلاً من أربعة فروع لكل مسار. تبقى جدولة ظهور الأعلام وتراكم sticky كما هي، والخيار تجريبي `PS2X_VU1_FLAG_PACK=1` حتى القبول.

مراجعة مضادة: لا يجوز قراءة بايت لمسار غير مكتوب قد يكون غير مهيأ، ولا إسقاط البتات العالية منstatusالتي كان المسار القديم يجمعها،ولا تغيير قناع الوجهة أو اتجاهX/Y/Z/W،ولا تحديث العَلَم قبل دورته. تستخدم القراءات شرط الوجهة نفسه،وتحتفظstatusبكل البايتات،ويقتصر التغيير على حساب mac/status قبل منطق الجدولة الحالي. لاheadersأوrunnerأو ملفات صوت.

التحقق: مقارنة شاملة لمجموعة16حالةعلم لكل مسار و16قناعوجهة،مع إعادة المجموعة ببتاتعالية مصطنعة؛ ثم اختبارات النواة،ومراجع964أمرًا المسجلة بنفس حزمGIFوالحالةوالذاكرةوالدورات،ومقارنة متناوبة قبل/بعد. العينات تشمل كلفة أداة التحقق؛ لا تمثل نسبها CPU اللعبة أو FPS. لم يُقبل المرشح بعد.
