# البحث في مراجع الدوال المطابقة

أمر `decompref` في أدوات المشروع يبحث في نتائج decompdecomp المحلية دون تشغيل المترجم أو إعادة بناء النواة. يعمل باستخدام Python 3.10+ دون تثبيت اعتمادات الأداة الخارجية.

من جذر المشروع، اعرض المراجع الموجودة:

```powershell
python -m ps2l decompref
```

ابحث عن عنوان ظهر أثناء التشخيص؛ يقبل الأمر بداية الدالة أو عنوانًا داخلها، وكذلك أسماء `func_` و`FUN_` و`sub_`:

```powershell
python -m ps2l decompref 0x001D4DF0
python -m ps2l decompref func_001D4DE8 --source
python -m ps2l decompref 0x001D4DF0 --json
```

العنوان `0x001D4DF0` يقع داخل `func_001D4DE8` عند إزاحة8 بايت. يعرض الأمر المسار المطلق للمصدر والدليل. `--source` يطبع المصدر الذي فُحص، و`--json` يعرض البيانات المنظمة. عند استخدامهما معًا تكون أولوية العرض لـJSON.

الفحص يطابق بصمة ELF الكامل وبايتات الدالة في PT_LOAD، وبصمات المصدر وobject، ويساوي بيانات الفهرس مع سجل الدليل. يشترط أن الدليل سجل مطابقة تامة ورفض هدف معدل. يرفض الملفات المرجعية خارج مجلد الفهرس والتداخلات بين نطاقات الدوال. حالة `verified_artifacts` تعني أن ملفات الأدلة المخزنة متسقة الآن؛ الأمر لا يعيد تشغيل حكم المترجم أو يثبت سلوك اللعبة.

رموز الخروج:

| الرمز | المعنى |
|---|---|
| 0 | عُرضت مراجع اجتازت فحص الملفات والأدلة |
| 1 | لا تغطية مسجلة للعنوان؛ لا يعني فشل ترجمة اللعبة أو عدم وجود الدالة |
| 2 | تعذر التحقق، أو ملف تغير، أو مدخل غير صالح |

يمكن اختيار دليل وELF آخرين باستخدام `--index` و`--elf`؛ يجب أن تظل ملفات المصدر والأجسام والأدلة تحت مجلد الفهرس المختار.

المراجع الحالية **9 دوال فريدة /340 بايتًا**: ثمان آلية وواحدة بمساعدة سياق وإصلاح موثق للمسودة. تظهر الدالة المساعدة بعلامة `Assisted`؛ يفحص الأمر بصمة ملف context ويطابق وصف الإصلاح مع دليلها أيضًا. مثالها عنوان الاستدعاء غير المباشر `0x001D51A4` داخل الدالة `0x001D5160`. الأعداد ليست نسبة اكتمال اللعبة. [نتائج الاسترجاع وقيوده](DECOMPDECOMP_AUTOMATION_20261017.md). مصادر اللعبة المشتقة والأدوات المنزلة تبقى محلية ومستثناة من git؛ لا يشحن هذا الأمر أي كود لعبة.

التحقق: **12 اختبار وحدة** لاستخدام العناوين داخل الدالة، وصيغ الأسماء، ورفض المصدر وobject وcontext المتغيرة وELF المختلف، ورفض اختلاف الدليل وتداخل النطاقات وغياب اختبار الرفض والخروج من مجلد الأدلة وحدود ELF غير الصحيحة. جُرب الأمر أيضًا على الفهرس الحقيقي، وعلى عنوان غير مغطى، وعلى عرض المصدر. اجتاز فحص الأدوات الكامل335اختبارًا مع triage/diffview/agent؛ [تقرير الفحص](../artifacts/verification/decompdecomp-20261017-tooling-final.json). لا تغيير في runtime أو حزمة المستخدم أو الحفظ.
