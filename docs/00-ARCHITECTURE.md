# معمارية المشروع الفعلية

آخر مراجعة: 2026-10-10. هذا وصف للمكونات الموجودة، وليس وعدًا بتوافق جميع الألعاب.

## المسار الأساسي

```text
ELF وبيانات اللعبة الأصلية
        ↓
ps2xAnalyzer + خريطة الدوال + ملف تعريف النسخة
        ↓
ps2xRecomp → recomp/generated/SLUS_211.34/
        ↓                         + recomp/native/SLUS_211.34/
برنامج Windows أصلي ← البناء ← مصادر الرن تايم
        ↓
EE المترجم + خدمات PS2 + IOP + الرسوم والصوت والتحكم والحفظ
```

تُنَفّذ تعليمات EE المترجمة كـ C++ على الكمبيوتر. توجد طبقة توافق للأجهزة والخدمات، وبعض المعالجات والعمليات تستخدم التفسير أو المحاكاة. مصادر الوحدات الخاصة بـ RE4 تحتوي C++؛ ملف التعريف وحده لا يصف كل تنفيذ اللعبة.

## ملكية المكونات

| المسار | المسؤولية |
|---|---|
| `core/ps2xAnalyzer/` | تحليل البرنامج الأصلي |
| `core/ps2xRecomp/` | توليد الشيفرة والتوزيع بين الدوال |
| `core/ps2xRuntime/` | الذاكرة والخيوط وخدمات EE والرسوم والإدخال |
| `core/ps2xIOP/` | تنفيذ وخدمات IOP |
| `recomp/generated/` | المخرجات المولدة من اللعبة محليًا |
| `recomp/native/SLUS_211.34/` | مصادر ربط وحدات اللعبة المستقرة |
| `ps2l/` و`tools/` | إدارة البناء والتحقق والتشخيص |
| `profiles/` | هوية نسخة اللعبة وبيانات تحليلها ومراحلها |
| `dependencies/` و`integrations/` | مصادر المكونات المدمجة وتكييفها |
| `tests/` و`core/ps2xTest/` | اختبارات الأدوات والنواة |
| `artifacts/` | أدلة التجارب ونتائجها؛ بعض أهداف الاختبار لها مدخلات محلية هنا |

## حدود التحقق

اختبارات Python تختبر الأدوات، واختبارات C++ تختبر حالات محددة في النواة. برامج canary تتحقق من سلسلة تحويل برامج EE صغيرة معلومة النتيجة. الوصول إلى شاشة العنوان لا يثبت فك الفيديو أو تحميل المرحلة أو اكتمال اللعب.

أداة مقارنة ذاكرة PCSX2 موجودة، لكن لا توجد بوابة آلية مثبتة تقارن تشغيل اللعبة كاملًا بالمحاكي. أدوات `triage` و`agent` تساعد على التشخيص والتخطيط؛ لا يثبت وجودها إصلاح اللعبة ذاتيًا.

المشغّل التشخيصي والحزمة المحفوظة للمستخدم إصداران منفصلان. [الحالة الحالية](CURRENT.md) و[README](../README.md) يحددان نطاق الأدلة لكل منهما.

## التصحيح والأصل

أُرشف [التصور السابق](../ارشيف/2026-10-10/studies/00-ARCHITECTURE-before-evidence-review.md). قدّم وصفًا تصميميًا بوصفه معمارية منفذة، وتضمن أرقامًا وتعميمات عن مشاريع خارجية لا تصلح كدليل محلي. استُبدل بوصف يستند إلى مسارات المصدر والأدوات الموجودة. الأهداف المستقبلية تبقى في [خطة RE4](../RE4-FLAGSHIP.md) ولا تُعد ميزات مكتملة.
