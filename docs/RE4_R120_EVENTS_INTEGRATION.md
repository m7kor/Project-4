# أحداث غرفة R120 — اختبار ودمج

آخر تجربة `20261009T193033Z-7ab46629` أثبتت رفض الخيط 31 عند مدخل R120Event: عنوانه 0x1189CA0 = st1_0 base 0x1183100 + 0x6BA0. عاد R120Init وSceExec بالفعل، لكن الخيط المجدول لم يكن مترجمًا. الإطار الأخير بقي Loading.

أضيفت خمسة أجسام أصلية إلى st1_0: Main `[0x6B98,0x6BA0)`، Event `[0x6BA0,0x6EB4)`، callbacks S00 `[0x6EB8,0x7008)` وS01 `[0x7008,0x716C)` وS99 `[0x7170,0x7224)`. آخر نطاق ينتهي بعد JR/delay الأصليين، ويستبعد دوال مدير غير مرتبطة. المصدر الآن **16 جسمًا / 785 تعليمة / 284 مواقع نقل**. الأجسام السابقة الـ11 لم تتغير. كلمات الأجسام الـ785 طابقت الوحدة الأصلية؛ ثماني كلمات صفرية لا يطبع المولد تعليقات مستقلة لها، وفُحصت من الأصل أيضًا.

اختبار `artifacts/canary-r120-events` اجتاز **1,272 حالة / صفر اختلافات** و**936 توقفًا واستئنافًا إجرائيًا**، عند ثلاث قواعد تحميل وجيلَي بيانات. يستخدم memset الأصلية المطابقة لـ46 كلمة في ELF؛ بقية التوابع إجرائية لاختبار ABI. يشمل المسار الفرعي للـsub-screen، حالة Sofdec وأعلام التخطي بعد قراءة S99/S00، ترتيب الأحداث وألوان fade، معاملات الانتقال وموضع/دوران الغرفة، مسار SceExit غير العائد ومسار عودته في العينة. يقارن كامل RAM في Event/Main والسجلات المحفوظة؛ callbacks تقارن RAM خارج 32 بايت الألوان المحلية التي تتحقق معاملاتها عند fade، وتفحص المكدس والعودة. فروع callback تفحص phases −1/0/1/2/3/4، scenes 0/8/14/9، والفريمات المحيطة بـ0 و50 و120 و370؛ غير phase 1 لا يقرأ scene/frame بحسب الأصل فلا تُكرر مصفوفة غير مؤثرة.

العينة الأولى كشفت خطأً في توقع ترتيب الواردات: 0x6BD4 هو SceSleep(1)، وEnd/Start عند 0x6C50/0x6C58 مشتركان بين الفرعين، وsystemVISetBlack(1) يأتي عند 0x6C84. أكدت عناوين JAL في النسخة المنقولة بأسماء ELF الأصلية، وصُحح ترتيب العينة وعدد الانتظارات فقط. مصدر الترجمة لم يتغير لإرضاء الاختبار. سجل الفشل الأول محفوظ؛ callbacks الأولى اجتازت دون اختلاف، ثم أعيد الاختبار بالتوقع الصحيح. الدليل `r120-event-family-original-audit.json`.

دُمج المصدر نفسه المختبر في catalogue، وحُفظت ملفات catalogue/aggregate/profile والنسخة التنفيذية السابقة في `before-r120-events`. مولد loader profile تحقق من الهوية والمواقع قبل إصدار aggregate. النسخة التنفيذية تستدعي دوال اللعبة الأصلية؛ إجراءات العينة لا تُشحن.

بناء runner جارٍ بسجل `artifacts/verification/re4-r120-events-runner-build.log`. يلي اكتماله اختبار اللعبة مع الإعدادات السابقة وتشخيص التوقف عند أول عطل. الاختبارات الإجرائية لا تثبت تشغيل EVD أو FMV أو الصوت أو وصول المرحلة إلى اللعب، ولا تسمح بادعاء حل Loading قبل تجربة النسخة الفعلية.
