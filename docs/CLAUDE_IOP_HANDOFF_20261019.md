# مهمة Claude التالية: أداء مفسر IOP

الهدف تقليل كلفة مفسر IOP في RE4، خصوصًا الأفلام، دون تغيير دورات الأجهزة أو ترتيب الأحداث أو صحة التعليمات. هذه وثيقة توجيه للمستخدم، وليست دليلًا على بدء Claude.

أُدمج إصلاح ساعة SPU2 السابق واختُبر في بناء Codex. اختناق اللعب الحالي VU1 ويتولاه Codex؛ لا نتوقع أن يغلق تحسين IOP وحده فجوة سرعة اللعب. قياساتك السابقة قرينة لتحديد الأولوية، ويجب ربط القياس الجديد ببصمات البناء والمصادر الحالية.

ابدأ بقراءة `PS2_PROJECT_STATE.md` وتعليمات المشروع وتقريرك `docs/CLAUDE_AUDIO_FINDINGS.md`. افحص `core/ps2xIOP/src/emulator/core/iop_cpu.cpp` و`core/ps2xIOP/src/emulator/iop_emulator.cpp` ومسار جلب الذاكرة عند الحاجة. توجد بالفعل مسارات runCpu محسنة ومواعيد أحداث؛ قسها قبل اقتراح حل يكررها.

1. حدد أكبر كلفة فعلية: تنفيذ التعليمات، الجلب، قراءة وكتابة الذاكرة، تحقق الخدمات والمواعيد، الاستدعاءات أو الفروع. افصل قياس كلفة التشخيص عن التنفيذ؛ لا تعتمد على PS2X_PROFILE_IOP_HOST في الأفلام دون معالجة انحيازه المثبت.
2. اختر تحسينًا محدودًا يعالج الموضع المقاس. حافظ على MIPS load delay وbranch delay واستثناءات الذاكرة والمقاطعات وMMIO وRPC وDMA وSPU2. أي تجميع لتنفيذ تعليمات يجب أن يتوقف عند مواعيد الأحداث الفعلية؛ لا تقلل الدورات أو تتخطى خدمة لتسريع الرقم.
3. أثبت التكافؤ باختبار موجه ومقارنة الحالة والذاكرة والدورات والأحداث مع التنفيذ المحفوظ، واختبارات IOP الأربعة والجسر. وثق حالات الاختبار الواقعية، ولا تعتبر نجاح البناء دليلًا على التكافؤ الكامل.
4. قارن قبل/بعد بتكرارات متناوبة على نفس الحمل، مع بصمات المصدر والمشغل والإعدادات. عند الحاجة لجولة لعبة استخدم نسخة وحفظًا خاصين وتجربة قصيرة تجيب سؤالًا محددًا. لا تشغّل قياس أداء بالتزامن مع بناء أو اختبار آخر، ولا توقف عمليات غيرك. افصل مكسب المفسر عن أثره في سرعة الفيلم أو اللعب.

اعمل في نسخة وبناء خاصين تحت `tmp/diag/claude-iop`، وأدلة `artifacts/verification/claude-iop`، وتقرير `docs/CLAUDE_IOP_FINDINGS.md`. لا تعدل أصول المصدر المشتركة؛ سلّم patch مع SHA256 للملفات الأصلية والمعدلة. البناء المشترك والدمج والحزمة لدى Codex.

لا تعدل VU/VIF/DMA/GS أو ملفات runtime المشتركة أو headers أو runner. لا تنظف بناءً أو تعيد تهيئته، ولا تستخدم Git مدمّرًا أو تغيّر الحفظ أو الحزمة أو حالة المشروع الرئيسية. لا تفصل IOP/SPU2 إلى خيط آخر ضمن هذه المهمة؛ إذا أثبتت الحاجة فقدم تصميمًا مستقلًا للمراجعة. التزم باختيار المستخدم إبقاء اختبارات المستودعات الخارجية داخل العزل.

التسليم: السبب المقاس، الرقعة وبصماتها، أوامر التحقق ونتائجها الفعلية، جدول قبل/بعد، وحدود الدليل. إذا لم يثبت مكسب، صرح بذلك واحفظ التجربة دون اقتراح دمجها كتسريع.
