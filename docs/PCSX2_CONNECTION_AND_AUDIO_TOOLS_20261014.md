## تصحيح أداة الاتصال

كان الفحص السابق يرسل `mode=debugserver`، بينما مخطط الجسر يسمح بـ`auto/debug/pine`، لذلك رجع MCP validation error. نتائج الاتصال السابقة بهذا الطلب غير الصالح **لا تثبت عطلًا في DebugServer أو PINE**. هذا خطأ في أداة الفحص، ولم يُعالج بتغيير firmware المستخدم.

أضيف `pcsx2_probe_schema.py` لقراءة enum الفعلية واختيار قيمة مقبولة، ورفض المخطط غير المعروف. يحفظ probe arguments و`connection_attempt_valid` وحالة الاتصال بشكل منفصل؛ التقرير الموحد أصبح يشترط صلاحية طلب الاتصال أيضًا. metadata اللعبة تُقرأ إذا اتصل PINE. ثلاثة اختبارات جديدة تغطي المخطط الحقيقي وdebug-only والمخطط غير المعروف. يعمل probe بصيغتي `-m` وملفPython المباشر.
