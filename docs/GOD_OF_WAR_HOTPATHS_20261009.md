# تطبيق تحسينات الرن تايم وقياسها — 2026-10-09

مرجع الأفكار هو [God of War عند ca69e9b](https://github.com/KIexster/god-of-war-recomp/tree/ca69e9b1ddaa383123324cd203c9a88c0d3fdc6a)، خصوصًا patches `ps2recomp-vu1-blocks`, `ps2recomp-vif1-unpack-fast`, `ps2recomp-ee-timers-fast`. الملفات المرجعية محفوظة ببصماتها في `artifacts/research/20261009/gow-update/`. التغييرات المحلية تكييف محدود مع الرن تايم الموجود؛ لم تُنقل افتراضات backend الرسومي أو FINISH المبكر أو compiled VU.

## التنفيذ وضمان الصحة

- XGKICK: أزيل مسح مخزن 64 KiB عند كل بدء/إعادة ضبط، وأصبحت إعادة الضبط للبيانات الوصفية فقط. يُنسخ qword واحد عند نفس دورة النقل السابقة عبر memcpy إذا كان متصلًا، مع fallback يلتف بالبايت للحدود. لم يُنقل جمع الحزمة مسبقًا؛ تظل كتابات LSU المستقبلية مرئية في موعدها. يدعم المسار ذاكرة ذات حجم غير قوة اثنين.
- VIF1: نسخ المتجه المفكوك كاملًا عندما يكون decoded/handled ولا يوجد mask أو جمع row. يحتفظ مسار الحقول السابق بحالات fill-write والأقنعة وSTMOD offset/difference، ويظل فحص حدود الوجهة وفك الصيغ قبل الاختصار.
- EE timers: حفظ عنوان قيمة GIF_STAT داخل unordered_map بعد أول ظهور لها. العنصر يبقى صالحًا مع rehash، لكن clear في initialize يلغي العنوان قبل الاستخدام التالي. PS2Memory لا يسمح copy/move. لا تغيير لحسابات المؤقتات أو IRQ أو دورة تصفير FQC.

أضيفت اختبارات حزمة طويلة تليها قصيرة دون تسرب tail، والتفاف GIFtag وسط qword في ذاكرة 40 بايت بعد reset، وfill-write دون mask، وبقاء سجل GIF_STAT بعد نمو الخريطة وإعادة تهيئة نفس الذاكرة. الاختبارات القائمة تغطي store visibility وXGKICK المتتابع وUNPACK signed/unsigned وSTMOD والأقنعة ومؤقتات IRQ.

التحقق الصحيح جرى **بعد إعادة بناء ps2x_tests**: `artifacts/verification/gow-hotpaths-verification.json`، **519 C++ و126 Python وثلاثة فحوص أدوات، بلا فشل**. التشغيل الأول لفحص verify سبق إعادة بناء tests فكان 516؛ أُعيد الفحص بعد البناء ولا يُستعمل العدد القديم دليلًا على التغييرات الجديدة.

## القياس المحلي

البرنامج `core/ps2xTest/src/runtime_hotpath_bench.cpp` يستخدم بيانات إجرائية والرّن تايم الحقيقي دون ملفات لعبة. يحفظ checksum وعدد العمليات، ويرفض النتائج غير المطابقة. الهدف CMake اختياري `ps2x_runtime_hotpath_bench` لا يشحن مع اللعبة. أداة `tools/diagnostics/runtime_hotpaths.py` تحفظ بصمة التنفيذيين، تسخنهما وتتناوب في ترتيب before/after، وتتحقق من عدم تغير الملفات أثناء القياس.

دليل سبع جولات لكل مسار: `artifacts/research/20261009/gow-hotpaths/paired-comparison.json`، مع التنفيذيين before.exe/after.exe والقياسات الخام.

| --- | ---: | ---: | ---: | ---: |

عدد العمليات وchecksum متطابقان بين النسختين وكل الجولات. حالة GIF_STAT تعكس GIF_MODE/GIF_CTRL في low bits؛ صُحح توقع benchmark إلى 0x123450 قبل أخذ baseline، ولم يتغير runtime لإرضاء الاختبار.

هذه مدد عمل المضيف لمسارات معينة، وليست FPS ولا ادعاء تسريع لكل صيغة VIF1 أو اللعبة. قد تكون مساهمتها محدودة قبل بدء المرحلة. عائق _prolog غير المترجم لا تعالجه هذه التحسينات.

## اختبار RE4 بعد الدمج

اكتمل بناء runner خلال **655.0 ثانية**؛ معظم الزمن لإعادة ترجمة ملفات اللعبة المتأثرة بتغيير ترويسة الذاكرة. بصمة النسخة `c417bc5498c5e81fd255b9ef822b5bc5ebf0f853c18298475d166a055a3e306b`، حجم 86,802,944 بايت. سجل البناء `artifacts/verification/re4-gow-hotpaths-runner-build.log`.

تجربة `20261009T111753Z-548654bd` استخدمت ELF نفسه، إعدادات SIO2/SPU2/async نفسها وملف ضغطات START نفسه، دون تشغيل benchmark أو build أثناءها. انتهت بعد **300.235 ثانية بمهلة exit 124** وهدف واحد غير مترجم. سجلت تحميل sscrn وst1_0 عند القاعدتين السابقتين، بلا binding rejection، وأظهرت شاشة WARNING الأصلية بوضوح في frame-720.png. سجل missing-target كاملًا يطابق تجربة baseline `20261009T104830Z-50018396`: مصدر `0x2645C4` وهدف `0x118A800`، نفس السجلات وأثر العودة من constructor. هذا تحقق من بقاء مسار البدء المختبَر إلى العائق نفسه؛ لا يثبت صحة مرحلة اللعب أو عدم وجود أخطاء غير مرصودة.

الدليل `artifacts/research/20261009/gow-hotpaths/game-comparison.json`. بصمات بطاقة المستخدم وبطاقة التجربة وتنفيذي حزمة المستخدم متطابقة قبل/بعد. الحزمة العادية لم تُستبدل بنسخة التجربة؛ السواد بعد START واللعب والحفظ داخل المرحلة لم تُثبت سلامتها. لا قياس FPS للعبة في هذه الخطوة.
