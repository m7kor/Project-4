## سجل التصحيحات المهمة

| الاستنتاج القديم | التصحيح المعتمد |
|---|---|
| ملفات تعريف فقط دون C++ خاص باللعبة وبوابة مقارنة PCSX2 شاملة منفذة | توجد مصادر وحدات خاصة بـ RE4؛ أداة قراءة PCSX2 موجودة والمقارنة الفعلية غير منفذة |
| نجاح الأدوات والبناء يثبت اللعب | اختبارات الأدوات والنواة محدودة؛ اللعب الكامل غير مثبت |
| قراءة الحالة من DE2100+0x38 | حالة المفكك عند +0x48؛ نافذة 64 بايت من DE2100 لا تشملها |
| عامل الفيديو متوقف بالكامل | رُصدت إعادة تفعيل حارس العمل ودخولات تغذية؛ لا تثبت العينات سببًا وحيدًا للتوقف |
| وصول عينات SFD يعني نجاح فك الفيديو | يثبت وصول عينات فقط؛ تنفيذ IPU/DMA والفك والعرض يحتاج دليلًا |
| تكرار الملف يعني أنه زائد | ملفات متطابقة قد تستخدم في تشغيل واختبارات مختلفة |

التصحيحات التفصيلية والأدلة في الوثائق المرتبطة، خصوصًا `RE4_EVENT_READ_TRACE.md` و`TRACE_PAYLOAD_IDENTITY.md` و`TOOLING_AUDIT.md`. تُحفظ تقارير ما قبل الإصلاح كمقارنة تاريخية، ولا تُعرض كمرجع صحيح للتنفيذ الحالي.

## ما أُرشف

نُقلت الأصول التالية، مع البصمات وأسباب النقل في [سجل الدراسات](../ارشيف/studies-manifest-20261010.json):

- التصور السابق للمعمارية؛ استُبدل بوصف فعلي.
- العصف الذهني السابق `IDEA.md`؛ استُبدل برؤية تميز الأهداف عن الإنجاز.
- خطة RE4 السابقة؛ استُبدلت بمعايير إكمال وحالة موثقة دون تقليص النطاق.
- README قبل تدقيق 2026-10-05؛ يحفظ تاريخ الوصف السابق.

لا تُنقل المصادر والاختبارات والأدلة المطلوبة حاليًا لمجرد أنها قديمة. الدراسة التي تتضمن جزءًا صحيحًا وتصحيحًا موثقًا تُحفظ مع التصحيح؛ الفرضية غير المحسومة تبقى موسومة «قيد التحقق»، ولا يُدّعى أنها معتمدة أو أنها خطأ مثبت. هذه الجولة لا تصادق على كل سطر في المراجع الخارجية.
