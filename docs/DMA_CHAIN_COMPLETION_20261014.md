# اكتمال سلسلة DMA بدل قطع بيانات الرسم

## الدليل من اللعبة

جولتا v27/v28 استعملتا مشغل `24005f746cd96a2c36a42974bc020dc22af4544f94910aaffdee5e65be010b2d` قبل إصلاح الجامع. تسجيل DIRECT يحفظ مدخل VIF الذي يُكمل الأمر وحمولته المجمعة **قبل** تقسيم IMAGE. metadata يتضمن VIF_CODE وpendingIMAGE وعداد EE وملاحظات CHCR/TADR/QWC. السجلات لا تمثل بالضرورة حالة kick الأول، ولا يُستنتج منها اسم اللاعب.

v27 بدأ الالتقاط بعد EE6100؛ setup الصورة نفسه يتكرر بين الإطارات. ظهر payload صحيح 1024 بايت عند EE6125، لذلك لا يجوز نسبته إلى header المتضرر عند EE6129 لمجرد تطابق bytes الإعداد. v28 ضيّق البداية إلى EE6129 وجمع32 DIRECT، مع24 GPU في النافذة المعروفة:

## سبب فقد الذيل والإصلاح

جامع DMA في `ps2_memory.cpp` كان يستعمل `while(tagsProcessed < 4096)` ثم يتابع كأن السلسلة انتهت. لا ينتظر END/REFE/RET أو IRQ المفعّل إذا وصل الحد. اختباران على المسار الفعلي أعادا النمط: سلسلة4201 tag تفقد نهاية DIRECT، وsetup الصورة عند tag4096 يصل لكن REF64 الذي يحمل الصورة لا يصل. قبل الإصلاح **605 اختبارًا، 603 نجاح، فشلان**: [الدليل](../artifacts/verification/review-20261014-dma-cap-before-tests.log).

أزيل العدد الثابت. الجامع يمشي إلى نهاية السلسلة الفعلية؛ Brent cycle detection يقارن TADR/ASP/ASR0/ASR1 ويبلغ تكرار حالة التحكم دون إنهاء DMA مصطنع. لا يوجد visited allocation أو حد أعلى أكبر يخفي المشكلة مؤقتًا. اختبار4200 CALL لنفس RET subroutine، مع return address مختلف، يكمل8401 tag دون اعتبارها دورة. هذه ليست محاكاة streaming/MFIFO مع تعديل tags أثناء التنفيذ؛ دورة ثابتة غير منتهية تُبلغ بدل عرض نجاح وهمي.

كشف الاختبار أيضًا أن قراءة CHCR كانت تمسح STR. قنوات VIF0/VIF1/GIF المدعومة أصبحت تعيد حالتها دون تعديل؛ اكتمال العمل يمسح STR. normal QWC0 يكتمل مع D_STAT بدل الاعتماد على قراءة تعطي صفراً فقط. قراءة بقية القنوات القديمة لم تتغير، فلا يُدعى إصلاح كل DMAC.

اختبار حالة الانشغال النهائي يلاحظ CHCR **داخل callback تسليم DMA الفعلي** ثم بعد اكتماله؛ مجرد القراءة بعد kick المتزامن لا يثبت أن العمل ما زال جارياً. محاولتان سابقتان غير صالحتين لهذه النقطة محفوظتان: النقل كان ينتهي تلقائيًا قبل القراءة، وD_ENABLEW لا يعلق قنوات الرسم الحالية. لا تُحسبان شهادة للخلل. تعليق قنوات الرسم عند suspend يبقى عملاً منفصلاً مفتوحًا.
