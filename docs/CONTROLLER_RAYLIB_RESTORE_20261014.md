# استعادة قراءة يد GameSir المباشرة — v34

بناء المستخدم في `Resident Evil 4/Resident Evil 4.exe` عاد إلى قراءة raylib السابقة. لا تشغيل عبر Steam ولا تعديل لإعداداته. قراءة GLFW المباشرة بقيت للمقارنة الاختيارية فقط؛ التشغيل العادي يفرض `PS2X_PAD_FRESH_GLFW=0` ويزيل إعادة إدخال الاختبارات والتتبع. توزيع أزرار PS2 ومعالجة العصا والضغط وفصل الإدخال عند فقد التركيز محفوظة.

أضيف تتبع اختياري منفصل لنشر حالة اليد وقراءتها داخل IOP. عُزلت ملفات الحفظ في جولات الفحص. القراءة الأولى من Windows كانت محايدة؛ المستخدم أكد أنه لم يضغط أثناءها، فلا تعتبر دليل خلل. الجولة اللاحقة بالمسار الجديد سجلت التعرف والقراءة المحايدة وفقد التركيز فقط، ولم تثبت ضغطات فعلية.

**بالطريقة القديمة ثبت وصول الضغطات:** `artifacts/runs/gamesir-raylib-controls-v34/runtime.log` سجل ثلاث ضغطات A/PS2 Cross وزر Start، ثم نفس الحالات في القراءة الأصلية داخل اللعبة. فروق النشر إلى القراءة4 و4 و10 و17 مللي ثانية؛ ليست قياسًا من الضغط الفعلي إلى الصورة. التقرير `artifacts/verification/review-20261014-gamesir-raylib-v34-trace.json` يفرق بين التعرف والقراءات المحايدة والإدخال الفعلي. لا تسجيل عصا فعلي في هذه الجولة، ولا إثبات حركة شخصية أو لعب الحملة كلها.

اختبار الإقلاع60 ثانية و26 لقطة انتهى بإيقاف عملية الفحص المملوكة19060. الملفات الأصلية للحفظ لم تتغير. البناء نجح و612/612 اختبار محرك، و7/7 اختبارات Python ذات صلة بالتغليف والتحكم. أول محاولة لاختبارات GPU استعملت اسم متغير المحافظة الخاطئ وفشلت حالة واحدة؛ بعد تصحيح الاسم إلى `PS2X_GS_PRESERVE_CONTINUATIONS` نجحت612. لا يستخدم التشغيل العادي هذا الوضع التشخيصي. الاسم الصحيح لتفعيل حالتي GPU هو `PS2X_TEST_GPU_CONTINUATIONS`.

نُسخ المشغّل نفسه مع بصمة `ad8b9b87c3c70bbe697fc40ae90d1520c673b793ee31b53972c2e07966a42418` إلى الحزمة بعد نسخ احتياطي للمشغّل وملفات التشغيل السابقة. أُعيد فحص كل14 DLL المتعدية؛ الحزمة والحفظ مطابقان. تقرير التغليف: `artifacts/verification/review-20261014-raylib-v34-package.json`.

للتشغيل العادي استخدم `Resident Evil 4/Play.cmd` واضغط داخل النافذة قبل استخدام اليد. لفحص إضافي استخدم `Play-Controller-Test.cmd`؛ يسجل تغير الإدخال في `logs/controller-test.log`. أداة `tools/diagnostics/controller_trace_report.py` لا تعتبر القراءات المحايدة نجاحًا للتحكم.
