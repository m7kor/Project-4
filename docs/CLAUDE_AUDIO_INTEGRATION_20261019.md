# دمج إصلاح إعادة تشغيل ساعة SPU2

المقترح: قبول إزاحة الساعة في جسر NativeSpu2 بعد مطابقة بصمات تسليم Claude. يعيد IopMemory الساعة إلى صفر عند reset، بينما SetClock داخل kzspu2 لا يقبل الرجوع. InternalReset يضبط lClocks إلى ساعة الخلفية الحالية؛ لذلك يلزم تحويل جميع القراءات والكتابات وDMA والتقدم إلى حقبة الخلفية، وتحويل nextEvent بالعكس.

مراجعة مضادة: التعديل لا يغير دورات EE أو IOP ولا يحذف عينات. يحافظ على UINT64_MAX للحدث الغائب، ويتعامل مع الحدث المستحق قبل الإزاحة بإرجاع صفر. إعادة التشغيل المتكررة تقرأ آخر ساعة فعلية للخلفية، ولا تضيف الإزاحة القديمة مرتين. لا تعديل headers أو runners أو مكتبة PCSX2. سجل SPU2 يعرض ساعة الخلفية المستمرة؛ لا تقارن قيمته المطلقة بساعة IOP بعد إعادة التشغيل، بل الفروق بين النوافذ.

التحقق المخطط: بناء اختبار الانحدار أولًا مع التنفيذ القديم لإثبات فشله، ثم تطبيق الإصلاح والبناء التزايدي والاختبارات. مقارنة إقلاع قصيرة بنفس المشغل قبل وبعد الإصلاح، ومدخلات وحفظ معزولين. لا ادعاء بتسريع اللعب أو تحسن مسموع من هذا الإصلاح.

تجربة عدادات VU السابقة انتهت وأزيلت مناطقها المؤقتة؛ أكد restoration.json تطابق ملفات المصدر الثلاثة مع أصولها. المكتبة والـbench التشخيصيان يحتاجان إعادة بناء متسقة؛ المشغل المحفوظ قبل دمج الصوت هو 1d0942fc…cfb74 ويضم تجميع FMAC المباشر.
