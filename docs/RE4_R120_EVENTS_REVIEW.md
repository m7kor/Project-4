## تشخيص الخيط غير المترجم

StartThread كان يرفض مدخلًا غير مسجل بإرجاع KE_ERROR دون أي تشخيص. أضيف marker `[EE thread:missing-entry]` يحمل thread id وentry/source/arg، دون إعادة توجيه PC أو إيقاف runtime أو تغيير حالة الخيط. أداة run.py تصنفه كعطل، ويشمله خيار stop-on-fault. اختبار C++ تحقق من الخطأ وبقاء الخيط Dormant وPC الأصلي وعدم طلب الإيقاف ومحتوى الرسالة؛ اجتازت النواة 523 اختبارًا. اختبار Python يثبت كشف marker وإيقاف عملية التجربة مع حفظ الدليل. لم يُختبر marker داخل RE4 بعد؛ runner الجديد قيد البناء.

## حدود الدوال ومراجعة الانترو

R120Event يقرأ event/evd/r120s99.evd ثم r120s00.evd وr120s01.evd وفق حالة Sofdec وأعلام الإلغاء. يحجب الصورة ويغير ألوان fade وأعلام اللعبة ثم يطلب الانتقال إلى غرفة 0x100. لا يجوز إزالة هذه النداءات لإخفاء السواد. تمت مراجعة تعليماته وفروعه؛ اختبار السلوك الأصلي والجدولة والمشاهد لم يكتمل.

R120Main الأصلية كلمتان JR RA/NOP. callbacks عند 0x6EB8 و0x7008 و0x7170 تغير fade وأعلام الغرفة حسب مرحلة الحدث ورقم المشهد والفريم. النطاق المقترح من next-symbol للدالة الأخيرة `[0x7170,0x7408)` كان خاطئًا: انتهت الدالة عند JR/delay 0x721C/0x7220، وبعدها ثلاث دوال مدير مجهولة الأسماء تبدأ 0x7228 و0x7318 و0x7338. استُبعدت من نطاق callback قبل أي دمج. لم يستخدم catalogue أو runner مصدر المراجعة غير المصحح.

النطاقات المراجعة هي `[0x6B98,0x6BA0)`, `[0x6BA0,0x6EB4)`, `[0x6EB8,0x7008)`, `[0x7008,0x716C)`, `[0x7170,0x7224)`. ملف المراجعة المولد مع الأجسام السابقة أصبح 16 جسمًا / 785 تعليمة / 284 مواقع نقل. **هذا مصدر مراجعة فقط؛ لم يدمج أو يختبر سلوكيًا.** catalogue الفعلي ما زال على st1_0 ذي 11 جسمًا، وwep02 ذي 15 جسمًا.
