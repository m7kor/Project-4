# أدوات جرد المشروع

نُقلت من جذر `artifacts/` لتبقى الأدوات منفصلة عن نتائجها:

1. `project_inventory_scan.py`: جرد الملفات والمجلدات والأحجام؛ يشمل الملفات المخفية ولا يتبع الروابط.
2. `project_duplicate_scan.py`: بصمات الملفات غير الفارغة ذات الأحجام المتكررة، باستثناء بيانات Git؛ يكشف تغير الملف أثناء الحساب.
3. `project_classification.py`: يربط الجرد والتكرار بدور الملف وسبب القرار؛ لا ينقل أو يحذف شيئًا.

هذه أدوات لقطة **2026-10-10**، تستخدم جذر التشغيل الحالي ووجهة ثابتة `artifacts/project-audit/20261010/`. لا تشغّلها مباشرة إذا أردت الاحتفاظ باللقطة: غيّر وجهة الإخراج في الأدوات الثلاث إلى مجلد جديد أولًا. ثم شغّل من جذر المشروع بالترتيب أعلاه. مقارنة التكرارات تقرأ بيانات كثيرة وقد تستغرق وقتًا.

التصنيف حسب المسار والدور لا يثبت أن الملف غير مستخدم. النقل أو التنظيف يحتاجان مراجعة الاعتماد والروابط، وخاصة مصادر `recomp/native/` وملفات `artifacts/research/` المستخدمة في اختبارات.
